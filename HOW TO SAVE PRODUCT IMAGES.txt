HOW TO SAVE PRODUCT IMAGES
================================================================================

You never touch the code to add a picture. The bot looks for a file named
after the thing it belongs to, and uses it if it finds one. Get the name
right and the picture appears; get it wrong and that screen just shows as
plain text, and everything else still works.

Written against the shop as it stands on the date this was saved: 14 real
products across 7 top-level categories, none of them with a picture yet.
The full list is in section 5.

--------------------------------------------------------------------------------

   The file is named after the product's CODE, not its name on screen.

   The codes are listed in section 5. They are lower case, use underscores
   instead of spaces, and never carry the emoji or flags the on-screen name

--------------------------------------------------------------------------------
2. WHERE THEY GO
--------------------------------------------------------------------------------

   c:\Users\lb kalous\Desktop\mcwhite\images\

   Straight into that one folder. Not into a sub-folder inside it - the bot
   does not look inside sub-folders.

--------------------------------------------------------------------------------
3. WHAT KIND OF FILE
--------------------------------------------------------------------------------

   Allowed:      .jpg   .jpeg   .png   .webp

   NOT allowed:  .heic (what an iPhone saves by default), .mp4 and video of
                 any kind, .gif, .bmp, .avif, .tif. Convert to .jpg first or
                 the bot never finds it.

   Size:         keep it under about 5 MB. Telegram refuses bigger ones.
   Quality:      1280 pixels wide is plenty.

   If a product somehow has two allowed extensions at once, the bot takes
   .jpg first, then .jpeg, then .png, then .webp.

--------------------------------------------------------------------------------
4. STEP BY STEP
--------------------------------------------------------------------------------

   1. Find the product's code in section 5.
   2. Rename your picture to that code plus .jpg
      e.g. IMG_4417.jpg  ->  ds_shard_ketamine.jpg
   3. Drop it in the images folder from section 2.
   4. Stop the bot and start it again.
   5. Open that product in Telegram. The picture is there.

   Step 4 is not optional. The bot remembers a picture's Telegram file ID
   once it has sent it, so a file added while the bot is already running may
   not show up until it restarts.

7. MULTIPLE PHOTOS ON ONE PRODUCT, OR A SECOND IMAGE FOLDER
--------------------------------------------------------------------------------

   This bot's image lookup is simpler than some others you may have used:
   one file per code, no "2.jpg, 3.jpg" numbering for extra photos, no
   per-flavour pictures. If you want a product to flick through several
   photos, say so and it can be added - it is not there today.

--------------------------------------------------------------------------------
8. WHEN IT DOESN'T WORK
--------------------------------------------------------------------------------

   "I saved the file and the picture still isn't there."

   a) THE HIDDEN SECOND EXTENSION. This catches nearly everyone. Windows
      hides known extensions by default, so a file that looks like
      "ds_shard_ketamine.jpg" in Explorer can really be
      "ds_shard_ketamine.jpg.jpg", and the bot will not find it.

      Fix: File Explorer -> View -> Show -> File name extensions (tick it).
      Now you can see the real name. Rename it so it ends in exactly one
      .jpg

   b) DID YOU RESTART THE BOT? See section 4, step 4.

   c) WRONG FOLDER. It must be images\ itself, not a sub-folder.

   d) CAPITALS OR SPACES. "DS_Shard_Ketamine.jpg" and "ds shard ketamine.jpg"
      are different names from the real one. Every code is lower case with
      underscores, never spaces.

   e) HEIC FROM A PHONE. Looks like a photo, is not one of the four allowed
      types. Convert to .jpg.

   f) CHECK THE LOG. The bot writes a line when it looks for a picture and
      fails to upload one - the warning names the exact key it tried.

   "The picture shows above the text instead of behind it, or not at all."

      This bot has no built-in handling for a caption that is too long for
      a photo (Telegram's limit is 1024 characters under a picture). A
      product whose description runs long could fail to send its photo at
      all if this ever comes up - if you notice it on one of the longer
      product pages, say so.
